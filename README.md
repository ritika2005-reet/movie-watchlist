# Movie & Watchlist Platform

A movie discovery and watchlist web application built using HTML, CSS and JavaScript.

## Features

- Movie discovery dashboard
- Live movie search
- Genre filtering
- Minimum audience rating filter
- Movie sorting
- Add movies to watchlist
- Remove movies from watchlist
- Browser localStorage for watchlist persistence
- Login interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Vite
- Git
- GitHub

## Project Structure

- index.html - Main webpage
- src/main.js - Application logic
- src/style.css - Styling
- public/ - Public assets

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
npm install
npm run dev
